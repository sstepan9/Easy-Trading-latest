Easy Trading Russificator

Официальный русификатор для EasyTrading 06.26.02
Совместимость: Paper / Minecraft 1.21.x

Установка:
1. Установите основной плагин EasyTrading.
2. Скопируйте `EasyTrading-Russificator-1.21.x-06.26.02.jar` в папку `plugins`.
3. Перезапустите сервер.

Важно:
- Руссификатор работает только вместе с официальным плагином EasyTrading.
- После установки аддон автоматически переключает язык EasyTrading на русский.
- Для полного перевода названий предметов и блоков используется официальный файл локализации Minecraft 1.21.1.
